## 📋 Следующие шаги для запуска проекта

### 1. Установка зависимостей

**Backend:**
```bash
cd backend
npm install
```

**Frontend:**
```bash
cd frontend
npm install
```

### 2. Настройка базы данных

Установить PostgreSQL 16+ и создать базу данных:
```sql
CREATE DATABASE rfm_analysis;
```

Настроить `.env` файл в backend:
```env
DB_HOST=localhost
DB_PORT=5432
DB_USERNAME=postgres
DB_PASSWORD=your_password
DB_DATABASE=rfm_analysis
```

### 3. Запуск проекта

**Backend:**
```bash
cd backend
npm run start:dev
```

**Frontend:**
```bash
cd frontend
npm run dev
```
